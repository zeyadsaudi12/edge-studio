# منصة استوديو EDGE الإبداعي | EDGE Studio Platform

منصة ويب متكاملة لعرض أعمال التصميم الجرافيكي (سوشيال ميديا، مطبوعات، هوية بصرية)، واستقبال طلبات العملاء مع حساب التكلفة وإرسالها عبر واتساب، مربوطة بقاعدة بيانات **MongoDB** ومحمية بلوحة تحكم إدارية.

---

## 🚀 تشغيل المنصة

### 1. تشغيل الخادم (Backend Server)
```bash
npm start
```
أو في وضع التطوير مع التحديث التلقائي:
```bash
npm run dev
```

### 2. الروابط الأساسية:
- **الموقع الرئيسي للعملاء**: [http://localhost:3000](http://localhost:3000)
- **صفحة تسجيل دخول المسؤول**: [http://localhost:3000/login.html](http://localhost:3000/login.html)
- **لوحة تحكم الإدارة المحمية**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## إعدادات البيئة

أنشئ ملف `.env` محلياً ولا ترفع بياناته إلى Git:

```env
MONGODB_URI=mongodb://127.0.0.1:27017/edge_studio
JWT_SECRET=ضع_قيمة_عشوائية_طويلة_وفريدة
ADMIN_USERNAME=admin
ADMIN_PASSWORD=كلمة_مرور_قوية_وفريدة
```

في Vercel، أضف `MONGODB_URI` و`JWT_SECRET` و`ADMIN_PASSWORD` إلى **Environment Variables** لكل بيئة مستخدمة. الخادم يرفض التشغيل في الإنتاج إذا لم يُضبط `JWT_SECRET`. لا يوجد حساب أو كلمة مرور افتراضية؛ يُنشأ حساب المسؤول الأول عند توفر قاعدة البيانات و`ADMIN_PASSWORD`. في التشغيل المحلي فقط، إذا لم تُضبط كلمة المرور، ينشئ الخادم قيمة مؤقتة عشوائية ويعرضها مرة واحدة عند إنشاء الحساب.

إذا سبق رفع ملف يحتوي أسراراً إلى مستودع عام، اعتبر القيم مكشوفة وغيّر كلمات المرور ومفاتيح الاتصال والتوقيع من مزوديها قبل إعادة النشر.

### رفع صور المشاريع

صور المشاريع الجديدة تُرفع مباشرة إلى Cloudinary ولا تُخزّن كـ Base64 في MongoDB. أضف متغيرات `CLOUDINARY_CLOUD_NAME` و`CLOUDINARY_API_KEY` و`CLOUDINARY_API_SECRET` إلى بيئة الخادم (ويجب أن تكون إعدادات الاتصال نفسها موجودة محلياً و/أو على Vercel). لا يحتاج المتصفح إلى السر؛ يوقّع الخادم طلب الرفع بعد التحقق من جلسة المسؤول. يمكن أيضاً إضافة مشروع برابط صورة HTTPS.

المشاريع القديمة التي تحتوي صوراً بصيغة Base64 ستظل تعمل، لكنها لا تُنقل تلقائياً إلى Cloudinary. أعد رفع هذه الصور إلى التخزين السحابي لتقليل حجم استجابة المعرض.

### رفع الكتب بصيغة PDF

تستخدم مكتبة الكتب إعدادات Cloudinary نفسها. عند رفع PDF أكبر من 9 MB، يُعاد تصيير صفحاته كصور مضغوطة ثم يُقسّم تلقائياً إلى ملفات PDF أصغر من 9 MB، وتُرفع الأجزاء ككتاب واحد. هذا التصغير يحول النص داخل النسخة المعروضة إلى صور فلا يعود قابلاً للبحث أو النسخ. يدعم المسار حتى 1000 صفحة و100 جزء؛ إذا تجاوز الملف ذلك، قسّم المحتوى إلى كتب منفصلة.

## 🍃 إعداد قاعدة بيانات MongoDB

افتح ملف `.env` وقم بضبط متغير `MONGODB_URI`:

### للربط مع قاعدة بيانات محلية (Local MongoDB):
```env
MONGODB_URI=mongodb://127.0.0.1:27017/edge_studio
```

### للربط مع قاعدة بيانات سحابية (MongoDB Atlas مجاناً):
```env
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/edge_studio?retryWrites=true&w=majority
```

## 🛡️ ميزات الأمان وحماية لوحة الأدمن
1. **بوابة دخول آمنة (Authentication Gate)**: يتم التحقق من الجلسة قبل استخدام لوحة الإدارة، كما تُحمى عمليات الإدارة على الخادم.
2. **تشفير كلمات المرور**: باستخدام خوارزمية التشفير القياسية `bcryptjs`.
3. **رموز التحقق الرقمية (JWT Tokens)**: يتم التحقق من صحة وصلاحية الجلسة في جميع مسارات الـ API الحساسة.
4. **حماية مسارات الطلبات والمشاريع**: لا يمكن استعراض أو تعديل أو حذف بيانات الإدارة إلا بواسطة مسؤول النظام المسجل.
