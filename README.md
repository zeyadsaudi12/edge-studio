# منصة استوديو EDGE الإبداعي | EDGE Studio Platform

منصة ويب متكاملة لعرض أعمال التصميم الجرافيكي (سوشيال ميديا، مطبوعات، هوية بصرية)، واستقبال طلبات العملاء مع حساب التكلفة وإرسالها عبر واتساب، مربوطة بقاعدة بيانات **MongoDB** ومحمية بلوحة تحكم إدارية.

---

## 🚀 تشغيل المنصة

### 1. تشغيل الخادم (Backend Server)
```bash
npm start
```
أو في وضع التطوير مع التحديث التلقائي:
```bash
npm run dev
```

### 2. الروابط الأساسية:
- **الموقع الرئيسي للعملاء**: [http://localhost:3000](http://localhost:3000)
- **صفحة تسجيل دخول المسؤول**: [http://localhost:3000/login.html](http://localhost:3000/login.html)
- **لوحة تحكم الإدارة المحمية**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

---

## 🔒 بيانات تسجيل الدخول الافتراضية للوحة الأدمن
- **اسم المستخدم (Username)**: `admin`
- **كلمة المرور (Password)**: `edge2024admin`

> يمكنك تعديل اسم المستخدم وكلمة المرور من ملف `.env` في أي وقت.

---

## 🍃 إعداد قاعدة بيانات MongoDB

افتح ملف `.env` وقم بضبط متغير `MONGODB_URI`:

### للربط مع قاعدة بيانات محلية (Local MongoDB):
```env
MONGODB_URI=mongodb://127.0.0.1:27017/edge_studio
```

### للربط مع قاعدة بيانات سحابية (MongoDB Atlas مجاناً):
```env
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/edge_studio?retryWrites=true&w=majority
```

---

## 🛡️ ميزات الأمان وحماية لوحة الأدمن
1. **بوابة دخول آمنة (Authentication Gate)**: أي محاولة للوصول إلى `admin.html` بدون تسجيل دخول يتم تحويلها فوراً إلى `login.html`.
2. **تشفير كلمات المرور**: باستخدام خوارزمية التشفير القياسية `bcryptjs`.
3. **رموز التحقق الرقمية (JWT Tokens)**: يتم التحقق من صحة وصلاحية الجلسة في جميع مسارات الـ API الحساسة.
4. **حماية مسارات الطلبات والمشاريع**: لا يمكن استعراض أو تعديل أو حذف أي طلب إلا بواسطة مسؤول النظام المسجل.
